# OCS Replenishment Automation

## Overview
Headless Selenium automation for downloading OCS Order Template and Catalogue
on Ubuntu LTS servers.

## Requirements
- Ubuntu 20.04 / 22.04 LTS
- Python 3.9+
- Google Chrome
